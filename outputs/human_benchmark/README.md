# Human benchmark evidence

This directory stores permanent Phase 1 human benchmark evidence generated by `python tools/human_benchmark.py`.

- `attempts/*.json` are lifecycle-updated until finalization and immutable after completion.
- `results.jsonl` is the append-only attempt-event index.
- `summary.json` is regenerated from attempt files and emphasizes first completed attempts.

Synthetic smoke outputs must use a different output directory and never belong here. See `docs/human-benchmark.md` for the protocol and information-parity rules.
