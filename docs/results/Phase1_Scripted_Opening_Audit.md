# Phase 1 scripted-opening audit

Date: 2026-08-14  
Audit ID: `20260814_phase1_opening_full_seed42`  
Scope: environment contract only; no PPO actions or model-performance evaluation

> **Finding: historical Phase 1 uses a mixed opening.** The intended two-unit Turn-2 handoff occurs on 3,038/5,517 maps (55.07%). On 2,479 maps (44.93%), both scripted moves succeed but the Turn-1 move returns the original warrior to the capital. This makes warrior spawning unavailable, so the opening silently hands control over with one unit.

No opening behavior was repaired for this audit. Opt-in instrumentation records the existing action choices and exceptions; the ordinary no-recorder path remains unchanged.

## Suspected human-benchmark map

`human_benchmark/map_003696.csv`, reset seed 42, reproduced the reported handoff exactly:

- Turn 2, 5 stars, 4 SPT, one city;
- one owned/visible warrior, unit 2, on capital `(3,5)`;
- both animal harvests and Workshop succeeded;
- Turn-0 move succeeded: `(3,5) → (2,4)`;
- Turn-1 move succeeded but reversed onto the capital: `(2,4) → (3,5)`;
- the capital was occupied, so no warrior spawn action was available or attempted;
- both end-turn actions succeeded;
- no exception was raised or swallowed.

The same map produced the same category under seeds 1, 42, and 123.

## Root cause

The failure is not an exception and not a field-name mismatch. `choose_and_execute_best_move()` scores the Turn-1 moves using diagonal movement and pressure toward the map center. It does not exclude or penalize moving back onto the capital, and the call supplies no second-unit dispersion target because the second unit has not yet been spawned. On 2,479 maps, the highest-scoring legal move therefore returns the only warrior to the capital.

The subsequent spawn search is correctly performed against the new legal-action list. Because the capital is occupied, the Java environment offers no warrior spawn there. The current opening treats a missing spawn match as optional and continues without raising, producing a one-unit handoff. The permissive exception handling is risky, but it did not activate anywhere in this fixed-seed dataset audit.

Successful examples diverge at Turn 1: their selected second move remains off-capital, after which `SPAWN by city 1 : WARRIOR` is available and executes. Representative full traces for three successful and three failed maps are retained with the audit artifacts.

## Scientific interpretation

The Seed-1 checkpoint was trained on the historical mixed-opening task: 55.02% of its 5,000 training maps handed off two units and 44.98% handed off one. The canonical validation suite used 56.40% two-unit and 43.60% one-unit openings. The 1.38 percentage-point difference is small, and both pools were generated by the identical wrapper behavior.

The 3,000-episode validation result therefore remains internally valid for the **historical mixed-opening Phase 1 environment**. It must not be described as performance under a universally two-unit opening. Human/model interface parity was maintained because both use the same wrapper, but official human benchmarking is paused: its intended opening contract was wrong, and no completed first attempts should be recorded until a policy decision is made.

The pristine test pool received no policy actions and no capability scoring during this audit. Its opening distribution was inspected only to verify the environment contract. Pristine model evaluation remains paused.

If the intended task requires two units on every map, repairing the opening changes the initial-state distribution on approximately 45% of training maps. The existing checkpoint would remain valid evidence for the historical task, but a scientifically clean corrected-task result would require retraining and new validation before pristine-test evaluation.

## Recommendation

**Recommendation D: fix the environment and retrain before pristine test**, if the two-unit opening is confirmed as the intended Phase 1 contract.

Before implementing that repair, freeze this audit and decide the corrected rule explicitly—for example, whether Turn-1 movement must exclude the capital or whether spawning must precede the second move. Then add a fail-closed two-unit handoff invariant, retrain on the corrected environment, rerun validation, and only afterward consider pristine-test evaluation. Preserve the Seed-1 checkpoint and its validation result as historical mixed-opening evidence.

## Corrective closure: v2 guaranteed two-unit opening

The historical findings above remain unchanged. The selected correction introduced `v2_guaranteed_two_unit`: only the Turn-1 scripted move excludes the own-capital destination before using the existing scorer; the second-warrior spawn is mandatory; required phases raise diagnostic errors; and reset checks the complete two-warrior Turn-2 invariant. Normal policy-controlled actions are unchanged.

Corrected audit `20260814_phase1_opening_corrected_seed42` reset all 5,517 manifest maps with seed 42. Results were 5,000/5,000 train, 250/250 validation, 250/250 test-contract, and 17/17 human-benchmark two-unit handoffs.
